# Hash-killer
Tool to crack hash, only for legal usage

![](https://img.shields.io/badge/github-repo-blue?logo=github)

## Made for:
- red teams and pentesters to deal with hashed text

## Options:
- lightweight for fast and simple usage
- can be installed fast and easily

## Technologies used:
- **Language:** Python 3
- **Standard Library:** `re` (Regex parsing), `argparse` (CLI arguments), `hashlib` (Hash library), `bcrypt` (bcrypt hash algorithm),`rich` (output formatting)
- **Custom Modules:** BetterRich (custom output formatting)

## Install and Run:
- make sure you have installed python 3
- Download the repo
- cd to the repo directory
- install the requirements `pip install -r requirements.txt`
- run `python3 main.py -h`
- based on help, run the script how ever you want

## Test:
- There is a little hash generator and wordlist for you to test the script
